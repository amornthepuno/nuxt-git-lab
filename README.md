# Nuxt Git Lab 🧪

โปรเจกต์ Nuxt 4 ขนาดเล็กสำหรับฝึก **Git + GitHub + Claude Code** ตั้งแต่ commit แรกจนถึง Pull Request, Code Review, CI และ Merge

👉 **เริ่มที่คู่มือ: [docs/GIT-TUTORIAL.md](docs/GIT-TUTORIAL.md)**

## Quick start

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # unit tests
npm run build   # production build
```

ต้องใช้ Node.js 20+ (แนะนำ 22 LTS)
